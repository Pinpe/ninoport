中转站或本地服务都填这里；留空则用 OpenAI 官方端点。

原样交给 API，写错了会报错；拿不准就去服务商的文档里抄一份。

这一轮模型最多能写多少 token，写到这个数还没说完就会被截断。三个协议都要求带上它。

官方认的是 none / minimal / low / medium / high / xhigh / max（默认 medium），none 等于让人别想、跟上面的开关重复了就没列。并非每个模型都认全，中转站也可能压根不认识这个参数，报错就把它留空。

每轮对话都会放在最前面，优先级最高。

一个实例就是一套 API Key ＋ 模型 ＋ 几个开关的组合。 填好之后它得到一个随机编号，点开就能直接对话——不用每次都去翻 是哪家中转站、该填哪个模型名。

配置和历史都只放在本机的几个 JSON 文件里，不上传、不联网， 除了你自己让它去调的那家 API。NinoPort 是开源的， 想改、想抄、想拆开看都随你。

模型偶尔会一本正经地胡说，接口报错也可能带上服务商的原话， 判断还是留给自己。
